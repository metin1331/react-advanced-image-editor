# react-advanced-image-editor-core

Headless image editor engine (crop, transform, markup, filters, export, undo/redo).

Used by [`react-advanced-image-editor`](../react-advanced-image-editor). Most apps should install the React package instead of this one directly.

```ts
import { loadImageSource, exportImage, createHistory } from 'react-advanced-image-editor-core';
```
